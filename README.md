# Samokat_GO_
Репозитарий
«Самокат GO» — учебный веб-проект сервиса аренды электросамокатов. Сайт помогает пользователям ознакомиться с услугами сервиса, выбрать подходящую модель электросамоката и узнать условия аренды.

Основные возможности

Просмотр информации о сервисе.

Ознакомление с каталогом электросамокатов.

Просмотр тарифов и условий аренды.

Заполнение демонстрационной формы заявки.

Просмотр контактной информации.

Используемые технологии

HTML5 — создание структуры веб-страниц.

CSS3 — оформление и адаптация интерфейса.

JavaScript — добавление интерактивных элементов.

Структура проекта

index.html — главная страница сайта.

css/ — таблицы стилей.

js/ — JavaScript-файлы.

images/ — изображения проекта.

Запуск проекта

Для просмотра сайта необходимо скачать файлы проекта и открыть index.html в браузере.

Назначение проекта

Проект разработан в рамках учебной практики для закрепления навыков создания, оформления и тестирования веб-ресурсов.

Примечание

Форма заявки предназначена для демонстрации интерфейса. Реальное бронирование электросамокатов и отправка заявок на сервер не реализованы.
